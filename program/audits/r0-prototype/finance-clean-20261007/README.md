## Reproduce

Use the dedicated loopback mock sandbox named `r0-local`, with its clock configured externally to the same frozen instant, SOS at 3013 and Admin at 3008 pointing to APIs 4200/4208. Do not run this fixture creator against production. From the repository root, after installing the existing audit-kit Playwright dependency:

```powershell
$env:SUITE_ROOT = (Get-Location).Path
$env:FINANCE_EVIDENCE_DIR = Join-Path $env:TEMP ('orgtik-finance-' + [guid]::NewGuid().ToString('N'))
node program/audits/r0-prototype/finance-current-runner.cjs
```

`FINANCE_SOS_API`, `FINANCE_ADMIN_API`, `FINANCE_SOS_WEB` and `FINANCE_ADMIN_WEB` override the loopback origins. `FINANCE_FIXTURE_PASSWORD` optionally supplies the documented staff mock fixture password. All origins are restricted to loopback HTTP and the runtime sandbox/clock are checked before mutation. Each invocation creates uniquely named disposable accounts and financial records; it never resets or advances the shared fixture. Reports contain no password, token, handoff code or idempotency key.

Four representative PNGs are tracked here; all 57 capture metadata records remain in the original report. Complete captures are generated by reproduction and remain in the original local run directory. They are not represented as additional tracked artifacts.
