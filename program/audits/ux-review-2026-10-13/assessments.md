# طريقة المراجعة وحدود الأدلة

المخرج الأساسي هو [README](README.md). الملف ده يوضح مصدر التقييمات المستقلة؛ ما يضيفش ملاحظات جديدة خارج سجل UX.

## Assessment A — التصميم ورحلات المستخدم

راجع WM وConsole بصورة مستقلة قبل قراءة B. استخدم الصور الحالية والملاحة وقراءة المصدر، مع إطار Nielsen. نتيجة23/40 كانت تقييمًا نوعيًا للشاشات وقت الجولة الأولى، **قبل** إصلاح Setup؛ مش درجة جديدة بعد الإصلاح، ولا قياس صلاحيات أوإتاحة كامل.

أبرز الأدلة: اختيار حقول ترجمة فيه أسماء صور ومسارات، قائمة إصدار طويلة، استيراد قبل مكتبة الوسائط، وConsole checklist كانت تفتح404. النتيجة الأخيرة اتقفلت في UX001؛ مشاكل الترتيب والاختيار الباقية محفوظة فيUX013–015/020. الصور تحت [assessment-a](shots/assessment-a/).

الجولة الإضافية للموقع حصلت في تاب Brave خاص،1536×735، وبحساب خيالي `.test`. التسجيل والتسليم لـSOS نجحوا. التسعير المحلي رجع503 أولًا؛ التقييم22/40 كان **عند العطل، قبل الإصلاح**. بعد إصلاح مفتاح الطلب المحلي، إعادة مستقلة أثبتت quote صالح، PayPal تجريبي مرة واحدة بقيمةCHF16، طلب مؤكد، Tasks في نفس المساحة، وفاتورة واحدة Paid. الصور W12–W16 تحت [assessment-a-website](shots/assessment-a-website/). حالة503 اتقفلت فيUX030.

## Assessment B — المصدر والديتكتور

ما قرأش نتيجة A أثناء تقييمه. CLI detector اشتغل وخرج بنجاح و`[]` في6 نطاقات WM وConsole والمكونات المشتركة، وبعدها نطاقين CRM وMarketing. مفيش rule findings في العينة؛ الأداة لم تبلغ بعدد الملفات اللي قرأتها. ده لا يختبر دقة المسارات أوفقد المسودات أوWCAG، ولا يثبت خلو المشروع من المشاكل.

Browser overlay ما اتنفذش لأن المتصفح المتاح يسمح بـDOM evaluation للقراءة فقط؛ لم يُحقن JavaScript أوتتغير الصفحة لإظهار detector. البديل كان AX وDOM وconsole وscreenshots، وده حد معلن للجزء الآلي.

من قراءة المصدر: WM Setup كان يبعث callback باسم غير مدعوم، Software Catalog يمسح المسودة عند تغيير الأداة، LocalizedField لا يربط الخطأ بالحقل، والنشر يفتقر لتأكيد واضح. العطل الأول اتصلح فيUX002، والباقي تحليل مصدر محدد؛ مفيش ادعاء إنه فقد مسودة أو نشر محتوى بالكتابة.

الجولة الإضافية CRM وMarketing استخدمت تابًا خاصًا1536×735 وEN. اتعمل contact خيالي، وتعديل الاسم اترفض بسبب هاتف وعنوان ما كانوش مطلوبين في الإنشاء. بعد استكمال قيم خيالية اتسجل التعديل، والحذف النهائي اتلغى؛ السجل ظل موجودًا عند إعادة الفتح. Label اتعمل واتعدل واسمه ظل بعد reload، والحذف اتلغى. الصور B01–B17 تحت [assessment-b-tools](shots/assessment-b-tools/). root فتح الأدلة المرتبطة وقرأ المصدر قبل إدراجUX037–039.

## التحقق الرئيسي والأدلة

root مشي Mona وNour والعضو المدعو، بالإضافة لإعادة التحقق من الأدلة المستقلة. لقطة98 في الجولة المتأخرة870×668؛ viewport الموبايل101/103–105/110/112/113/116/117/119/120 عند390×844. الصور الفعلية ارتفاعها843 أو844 بسبب تقريب الالتقاط، وحجم كل ملف وبصمته في [assets.json](assets.json). اللغة والثيم والـviewport المؤقتين اتردّوا قبل قفل التاب الخاص.

الأدلة المستقرة فقط مستخدمة لإثبات الشاشة. لقطات التحميل الأولية اتبدلت، و110/117 اتعاد التقاطهم بقص مطابق للـviewport كله لما API رجعت تصغيرًا غير صالح. امتداد كل صورة مطابق لصيغتها الفعلية؛ مفيش تعديل أوتركيب داخل الصورة.

التقييم لم يفحص قارئ شاشة كامل أو200% zoom أوكل وسائل الدفع أوكل المنتجات أوكل CRUD فرعي. مراجعة حذف نهائي انتهت بـCancel/Keep؛ استعادة Files القابلة للإرجاع اتنفذت. مفيش بريد خارجي أورسالة خارج النموذج أوميكروفون أوكاميرا أوCloud deployment. حدود المحاكاة جزء مقصود من المنتج المحلي.

الأسئلة الاستكشافية اتخطّت لأن المستخدم حدد الخطة والنطاق. قرارات PM محفوظة في التقرير الأساسي، والموافقة النهائية الوحيدة المطلوبة هي دمج PR حسب نص الخطة الصريح.
