# D-023: The default theme is light

| | |
|---|---|
| Status | **Accepted** (2026-09-30, G0 review) |
| Decided by | Yossef |

## Decision

Every dashboard opens in the **light** theme. Dark is a choice in the user menu, remembered per person (the shared `ot-theme` cookie). The draft recommended following the operating system.

## Context

Both themes ship from day one (D-003). The website's night look stays the website's.
