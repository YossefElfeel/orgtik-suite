# D-060: G-12 tax display is per region: GCC prices include VAT; Europe and Switzerland show prices excluding VAT, labelled; EU business customers with a valid VAT ID get reverse charge

| | |
|---|---|
| Status | **Accepted** (2026-10-07, G-R gate) |
| Decided by | Yossef |

## Decision

G-12 tax display is per region: GCC prices include VAT; Europe and Switzerland show prices excluding VAT, labelled; EU business customers with a valid VAT ID get reverse charge.

## Consequence

Fixes pricing row TAX-EU. Invoices show the tax line and the label the region needs.
