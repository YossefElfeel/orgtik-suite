# D-044: Everything stays local

| | |
|---|---|
| Status | **Accepted** (2026-10-01) |
| Decided by | Yossef |

## Decision

Everything stays local: no pushes, and @orgtik/ui isn't published, until GitLab access and sdk.orgtik.org publish rights exist.

## Consequence

Tarballs in orgtik-ui/releases/ and yalc remain the way apps get the library.

## Exception: hosted prototype (2026-10-07)

Yossef asked for the whole suite on GitHub and Vercel as a clickable frontend prototype. This is a one-off exception; the rule above still holds for the program's own repos.

- **What was pushed:** one snapshot of every app's current branch HEAD (2026-10-06), plus local-dev, @orgtik/ui and this repo, into the private repo https://github.com/YossefElfeel/orgtik-suite with **fresh history**. No original repo was pushed, and the client's git history (with the Q-004 secrets) didn't leave this machine. The content dashboard's hard-coded token was removed from the snapshot.
- **Where it runs:** 12 Vercel projects `orgtik-suite-*` (start at https://orgtik-suite-sos.vercel.app). The mock API runs as one function, `orgtik-suite-mock`. Its data is in memory and resets on a cold start.
- **@orgtik/ui** still isn't published. The snapshot carries each app's built `.yalc` copy.
- **Source of truth:** the local repos. The snapshot is refreshed from them, never edited in place and pushed back.
