# D-027: Status labels are written per viewer

| | |
|---|---|
| Status | **Accepted** (2026-09-30, G0 review) |
| Decided by | Yossef |

## Decision

Where a state reads differently from the customer's and from OrgTik staff's side, it has two labels. For example, a support ticket waiting on the customer is *Waiting for you* for the customer and *Waiting for customer* for staff. `status-matrix.csv` carries a customer label next to the default (staff) label; empty means the same. `<StatusBadge entity state viewer>` picks one.

## Context

The draft proposed one neutral label per state. The spec itself writes some labels from the customer's side ("Waiting for you").
