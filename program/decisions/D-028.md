# D-028: One lead pipeline

| | |
|---|---|
| Status | **Accepted** (2026-09-30, G0 review) |
| Decided by | Yossef |

## Decision

Leads from the website's forms go straight into Sales' CRM pipeline: one set of states for every lead, whatever its source. The Website Manager's Leads screen is a view onto that pipeline filtered to website sources, with the page, bundle and UTM context the form captured. The pipeline: new → contacted → qualified → quoted → won or lost (a reason is required), plus unqualified, spam and duplicate.

## Context

The draft kept website leads and CRM leads apart. Sales' mock pipeline today is new, contacted, qualified, unqualified, scheduled; *scheduled* becomes an activity on the lead, not a state, when the Sales wave reconciles it.
