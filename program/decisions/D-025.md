# D-025: Glossary choices for German, French and the Save button

| | |
|---|---|
| Status | **Accepted** (2026-09-30, G0 review) |
| Decided by | Yossef |

## Decision

- **German register:** the generic forms the catalogs use today (*Mitarbeiter*, *Benutzer*), not gender-neutral ones.
- **German plan:** *Tarif*.
- **French plan:** *Formule*, so *Forfait* stays for service packages.
- **Save:** one word everywhere (*Save / حفظ / Speichern / Enregistrer / Salva*); "Save changes" is dropped.

## Context

The glossary v0 open questions (`glossary/README.md`). The glossary rows are updated to match.
