# D-053: the hosted mock keeps its data (write journal in Upstash Redis, sandboxes)

| | |
|---|---|
| Status | **Accepted** (2026-10-07) |
| Decided by | Yossef |

## Decision

The hosted mock (`orgtik-suite-mock`) stops losing data on a cold start. Every successful change is recorded in a write journal in Upstash Redis (Vercel Marketplace, free tier) and replayed after the seed. Data lives in sandboxes: `demo` (production), `preview` (pull-request previews and CI), `review-<n>` (UX reviews) and `local`. A reset clears one sandbox only.

## Consequence

- Yossef connects the Upstash store to the mock project once; Claude never handles its credentials.
- Seeds and ids must be deterministic (seeded random numbers, the mock clock); a mock app that can't replay deterministically keeps a snapshot of its store instead.
- Live updates over sockets remain unavailable on Vercel.
