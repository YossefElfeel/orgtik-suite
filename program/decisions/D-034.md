## Decision

Phase 2, the Website Manager and its mock API v2, starts now. The remaining G1 items (the Figma library, deferred by the owner, and publishing ui 1.0) no longer gate it, and the dashboard waves wait.

- The library is at 1.0.0-rc.2 with P1a and P1b complete, and VS-1 passes, so the CMS is built on it from its first screen.
- The content model follows the website as it is now, at the D-031 baseline `d76ee3b`. That includes the department case studies (D-032): one shared brief plus a block set per department, with sample-figure labels kept until approved.

## Order inside Phase 2

1. **S0: the shell.** EN and AR/RTL, light and dark, sign-in from the launcher, RBAC from the mock, and the no-access page.
2. **S1 on the CMS side.**
   - The v2 content model and a mock seeded from the website's current content. It is read from the website's source files; the website repo is not changed.
   - The Work area with the case-study editor comes early, because it's the newest part of the site.
3. **Connecting the website.** S1's extraction and the runtime API read (D-012) change code in the website repo. That needs the owner's go-ahead and the AGENTS.md update (D3) first, so it is asked before it starts.
