| | |
|---|---|

| Decided by | Yossef |

## Decision

G-04 seat model: seats per tool. The owner buys a seat count for each per-user tool and assigns seats to members; an invitation or a tool grant needs a free seat in that tool.

## Consequence

Replaces the default 'one seat count across every per-user tool'. USR Team, checkout, invitations and billing change accordingly (part of R1).
