## Decision (2026-09-30)

Accepted as proposed.



## Context

Connecting the website to the CMS touches every page file. The design must not change (D-000). SEO work also needs other changes: real paths instead of hash routes, per-route head tags, and eventually lifting `noindex`.

## Proposal

- Every pull request that touches the website shows **0 pixel differences in EN**:
  - on all 39 routes at 390, 768 and 1440 px, plus interaction states
  - with identical DOM text, headings and accessibility tree
- The only allowed differences are `href` values, head tags and tab titles.
- Three changes each need their own explicit approval:
  - real paths (S3)
  - prerendered heads (S3)
  - removing `noindex`, after the content is approved

## Consequences

- The extraction work is pure refactoring, with no CSS edits.
- Any diff stops the line until it's explained or fixed.
