# D-045: The pricing-override colour is the brand violet (brand tone, with an icon and a word), not the spec's orange

| | |
|---|---|
| Status | **Accepted** (2026-10-01) |
| Decided by | Yossef |

## Decision

The pricing-override colour is the brand violet (brand tone, with an icon and a word), not the spec's orange.

## Consequence

Orange stays reserved for warnings, so an override isn't read as a problem.
