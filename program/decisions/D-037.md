# D-037: The website's content stays in English for now

| | |
|---|---|
| Status | **Accepted** (2026-10-01) |
| Decided by | Yossef |

## Decision

No translations of the website's content are written now: neither drafts nor machine translations. The five languages stay what they are today:
- the Website Manager's own interface (en, ar, de, fr, it)
- its translation workflow, ready for when translators are chosen

The website shows English only (`publicLocales: ["en"]`).

## Consequences

- S5 builds the mechanics only: per-language addresses (`/de/…`), hreflang, the language menu going public per language, and Arabic RTL (D-036). No locale goes public.
- PM packet item "Who reviews the DE/FR/IT/AR copy" stays open.
