# D-077: DS v2 evolves the OrgTik brand

Status: accepted direction, 2026-10-09. G-DS1/G-DS2 visual acceptance remains pending.

## Decision

Preserve violet/plum branding, the aubergine rail in both themes and Montserrat headings. Add IBM Plex Sans for Latin UI alongside IBM Plex Sans Arabic; use tabular data numbers. Introduce low-chroma graphite surfaces/text, layered ink shadows, focus ring plus soft halo, consistent content/spacing/z-index tokens, comfortable/compact density, visible dark primary hover and reduced-motion-safe feedback.

Maintain the JSON-to-CSS/TypeScript/Tailwind token pipeline, semantic surface roles, checked contrast pairs, Base UI, RTL/Arabic metrics, status matrix and chart wrapper. Use an eight-color brand-related visualization palette separate from statuses; add the existing visualization check to CI in P2.

## Gates and limits

P1 supplies Foundations v2 plus three real specimens: Tasks list, HR leave Sheet and Account Home, each EN/AR × light/dark. Owner screenshot approval is G-DS1. P2 updates shared components, SuiteFrame, ecosystem/admin primitives and stories; Storybook review is G-DS2 before publishing `2.0.0-rc.1` or accepting regenerated references.

The website design is preserved. No website CSS, JSX or markup redesign is part of this decision. P3 may only overlay approved public-catalog data in `purchase-catalog.js`, with last-known-good fallback and pixel parity using equal fixture content. Intentional catalog text changes require a separate functional assertion; a before/after pixel diff with changed text cannot truthfully be reported as zero.
