# D-054: @orgtik/ui is a workspace package; pnpm workspace and Turborepo

| | |
|---|---|
| Status | **Accepted** (2026-10-07) |
| Decided by | Yossef |

## Decision

Inside the monorepo, every app depends on `packages/ui` as `workspace:*`. The repo becomes one pnpm workspace with one lockfile, and Turborepo builds the library before the apps. yalc copies (`.yalc/`) and the release tarballs are retired.

## Consequence

- A library change and the app changes it needs land in one pull request.
- Vercel rebuilds only the projects whose app or dependencies changed (`turbo-ignore`).
- Each app's phantom dependencies are fixed when it moves to pnpm's strict `node_modules`.
- Ends the yalc + pnpm gotcha where library types silently became `any`.
