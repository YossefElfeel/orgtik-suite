# D-059: 'Website Manager' sold on the website is a managed website service: buying it opens a service request for OrgTik's team

| | |
|---|---|
| Status | **Accepted** (2026-10-07, G-R gate) |
| Decided by | Yossef |

## Decision

'Website Manager' sold on the website is a managed website service: buying it opens a service request for OrgTik's team.

## Consequence

The internal Website Manager (D-002) stays OrgTik's own CMS. The website order mapping treats it like the other services. Resolves SR-009.
