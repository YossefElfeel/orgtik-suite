# D-058: The platform's price resolver (spec 03) is the single price authority; the website reads prices and products from the platform

| | |
|---|---|
| Status | **Accepted** (2026-10-07, G-R gate) |
| Decided by | Yossef |

## Decision

The platform's price resolver (spec 03) is the single price authority; the website reads prices and products from the platform.

## Consequence

Supersedes A7's 'prices stay in the website catalogs'. The website shows per-user prices in the visitor's region and currency from the platform API at runtime; its catalogs keep only presentation (names, capabilities, images). Website orders are priced by the platform, never by the request (fixes pricing rows C3/R1). Resolves SR-003 and SR-017.
