# D-035: The website connects to the Website Manager on a local branch

| | |
|---|---|
| Status | **Accepted** (2026-09-30) |
| Decided by | Yossef (the website's owner) |

## Decision

The work that connects orgtik-website to the Website Manager (plan S1 extraction and S3: `AGENTS.md` update, a data layer reading the CMS API, real addresses instead of `#` links, head and SEO tags) happens on a **local branch** of orgtik-website, never pushed. Every step proves zero visual change with the parity harness against the D-031 baseline (d76ee3b). The owner reviews and merges when he wants.

## Consequences

- `main` of the website stays as the owner left it; the drift protocol (D-031) still compares against it.
- If `main` moves while the branch is open, the branch is rebased onto it and the parity baseline is re-captured first.
