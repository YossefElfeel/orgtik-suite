# D-052: orgtik-suite is the source of truth; work goes branch → PR → Vercel preview

| | |
|---|---|
| Status | **Accepted** (2026-10-07) |

## Decision

The private monorepo `orgtik-suite` on GitHub is the only place the suite is changed. Every change is a branch, a pull request, a Vercel preview and checks, then a merge to `main`. The 13 local repos under `New sass/` are frozen as read-only archives (tag `archive/pre-monorepo-2026-10-07`, `FROZEN.md`), after the session still using them has stopped.

## Consequence

- Plan v2 (`plan-v2.md`) replaces the old plan's way of working; the old plan's product decisions, definition of done and audit method stay.
- Parallel sessions work in their own git worktree and branch; the old path-ownership rules and `mock.lock()` apply only to the local mock.
- The client's original git history (with the Q-004 secrets) still never leaves this machine.
- `@orgtik/ui` is still not published to sdk.orgtik.org (D-006 open).
- The owner's `orgtik-website` repository and Vercel project are never touched; the drift protocol (D-031) runs inside the monorepo.
- Decision numbers D-049, D-050 and D-051 belong to the 2026-10-06 work order (restored projects, Roadmap follows the owner's GitHub version, the sign-in success screen).
