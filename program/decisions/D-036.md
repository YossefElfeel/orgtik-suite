# D-036: Arabic on the website is the same design, mirrored; built now, public later

| | |
|---|---|
| Status | **Accepted** (2026-10-01) |
| Decided by | Yossef (the website's owner; plan open decision 11, D8) |

## Decision

The website's Arabic is the same design mirrored right to left. The infrastructure is built now on `cms/connect` (D-035):
- the Arabic typeface (IBM Plex Sans Arabic, D-010) with an Arabic-only `unicode-range`
- `:lang(ar)` type rules
- the page direction following the language
- physical CSS directions turned into logical ones

English must stay 150/150 identical to the baseline at every step. Arabic isn't shown to visitors: the language menu keeps its current options until Arabic content exists and is approved (D-037, D7).

## Consequences

- Mirrored screenshots of every page go to the owner for review before anything is public.
- Until translations exist, the mirrored layout is reviewed with the English text in it.
