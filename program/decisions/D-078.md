# D-078: hybrid radius for brand and density

Status: accepted, 2026-10-09. Amends D-022 for the suite dashboards; website appearance stays unchanged.

## Decision

| Role | Radius |
|---|---|
| Primary actions, chips, badges, segmented controls, avatars | Pill |
| Fields, table/toolbar buttons, menu items | 8px (up to 10px only where a documented component needs it) |
| Cards | 12px |
| Dialogs and overlays | 16px |
| Large panels | 20px |

The brand pill remains on primary actions. Dense controls no longer inherit D-022's universal pill requirement. Define semantic component tokens instead of distributing new literals throughout the apps. P1 specimens demonstrate both shapes at comfortable and compact density before wider adoption.
