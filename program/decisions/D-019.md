## Context

ADM-27 specifies content management in the admin back office: pages, FAQ, blog and portfolio, with SEO per language and a "single language" option. The Website Manager (D-002) already manages everything on the website, with a slug and metadata per page and entry. Building both would duplicate the work and split the source of truth.

## Proposal

- ADM-27 **is** the Website Manager. ADM links to it with single sign-on.
- The spec's fields map onto its content model:
  - blog → Insights articles
  - portfolio → Work case studies
  - FAQ → FAQs
  - pages → Pages
- The spec's "single language" option becomes the Website Manager's rule: every public language is ready, or its absence is explicitly acknowledged.


## Decision (2026-10-01)

Accepted by Yossef: The spec's ADM-27 "Content" is delivered by the Website Manager.
