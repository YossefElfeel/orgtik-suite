# D-020: Namespaced --ot-* tokens, with a per-app bridge during migration

## Context

- The apps use shadcn's generic variables (`--primary`, `--secondary`, `--muted`), and each app gives them different meanings.
- They also carry 981 raw hex values.
- Apps migrate one wave at a time, so old and new styles must work side by side inside one app.

## Proposal

- Every library token is namespaced `--ot-*`, in three tiers:
  - primitives (`--ot-color-plum-500`)
  - semantic (`--ot-bg-surface-raised`)
  - component (`--ot-button-height-md`)
- No generic names like `primary` or `muted`. Those are where today's bugs come from, and avoiding them lets both systems coexist.
- Each app gets a **bridge** stylesheet mapping its old variables onto `--ot-*`, for example `--primary: var(--ot-action-primary-bg)`. The bridge is deleted at the end of the app's wave.

## Consequences

- Lint rules (`no-raw-color`, `no-default-palette`) count down each app's debt.
- Dark mode turns on for an app when its raw-colour count reaches zero.


## Decision (2026-10-01)

Accepted by Yossef: Namespaced `--ot-*` tokens plus a per-app bridge, removed at the end of each app's wave.
