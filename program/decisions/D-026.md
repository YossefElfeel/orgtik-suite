| | |

## Decision

One banner at a time, in this order: workspace suspended → tools read-only → payment failed → trial ends soon → beta billing → price change → downgrade scheduled. "Viewing as customer" is a permanent ribbon outside that rule.

## Context

The spec (USR-00) says one banner by priority without giving the order (`status-matrix/README.md`).
