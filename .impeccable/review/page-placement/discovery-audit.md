## Ordering and preview considerations

- The current page section order can be changed by presentation settings, so guidance says “below/after” using the normal template order but avoids pretending the editable text itself is the section identity.
- Service, Software and About moving strips render directly after the main banner. Their manager tabs now follow the banner too. Stable titles identify the scrolling service/product names.
- Work and Insights absent strips should remain visibly retained/unplaced rather than moving a useless editor tab into the apparent website order.
- Work detail reviews have no safe current overview target; this metadata suppresses preview until a real detail route is selected by an appropriate resolver.
- Software capabilities preview may use the existing permitted detail-route resolver; the metadata explains the required product state.
